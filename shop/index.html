        imali_bookkeeper is the front agent. It reads and writes the book through five site tools, hands written statements to statement_writer, and asks bonde_wholesale, the network of Bonde Wholesale on another website, for prices.

        What stays safe

        Every save opens a dialog with the exact entries. The agent cannot send money, message anyone or delete an entry. This browser contacts another site only after you approve it, and your key goes only to the model provider you chose.
